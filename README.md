# Student Management System

A Python and MySQL-based CLI application designed to automate school administrative records, including student profiles and multi-subject examination marks.

## Features

- **Student Details Management**: Add, search, and delete comprehensive personal records (Roll Number, Admission Number, Parent Names, State, Enrollment Date).
- **Academic Performance Tracker**: Insert, update, query, and remove subject marks across different examination terms (`PT-1`, `HALF-YEARLY`, `PT-2`, `PREBOARDS`, `BOARDS`).
- **Relational Persistence**: Uses MySQL for relational data integrity, primary keys, and query filtering.

## Tech Stack

- **Language**: Python 3.x
- **Database**: MySQL 8.0+
- **Driver**: `mysql-connector-python`
